# Text-Play 게임 UI 재구성 설계

---
## 목표

Text-Play 플레이 화면을 고정형 게임 화면으로 재구성한다. 기존 오른쪽 고정 패널과 중첩 스크롤을 제거하고, 중앙 장면 이미지·반투명 스토리 상자·추천 답안·직접 입력을 한 화면에서 사용할 수 있게 한다.

---
## 승인된 결정

- 데스크톱은 전체 창 안에서 동작하는 고정형 게임 화면을 사용한다.
- 작은 화면에서는 같은 기능을 세로로 재배치한다.
- 스토리 상자는 장면 이미지 하단에 겹쳐 표시하고 배경이 보이도록 반투명 처리한다.
- 실제 EXE 창 크기는 설정한 해상도에 맞춰 변경한다.
- AI 공급자 선택은 UI만 제공하고 실제 로컬 GPU 연결은 이번 범위에서 제외한다.
- 다크 판타지 글래스, 미니멀 SF HUD, 클래식 비주얼 노벨 테마를 모두 제공한다.
- 벡터 장식은 코드 기반 SVG로 제작한다.
- 저장과 불러오기는 각각의 버튼으로 열고, 수동 슬롯 6개를 2행×3열로 표시한다.

---
## 화면 구조

상단바는 세 영역으로 구성한다.

- 왼쪽: 스토리 제목과 메인 화면 이동 기능
- 중앙: 체력, 정신력, 골드 상태 칩
- 오른쪽: 저장, 불러오기, AI 공급자, 설정 버튼

본문은 장면 무대와 명령 도크로 구성한다.

- 장면 무대는 가능한 큰 영역에 이미지를 비율 유지 방식으로 출력한다.
- 현재 장소와 장면 제목은 이미지 위에 작은 캡션으로 출력한다.
- 스토리 상자는 이미지 하단에 겹치며 반투명 배경과 흐림 효과를 사용한다.
- 명령 도크 상단에는 기존 선택지를 Mock AI 추천 답안으로 표시한다.
- 명령 도크 하단에는 직접 입력, 전송, 응답 중지, 재시도 상태를 표시한다.
- 세부 스탯, 인벤토리, 퀘스트는 상단 상태 칩을 눌러 여는 팝업에 표시한다.

데스크톱에서는 문서 전체 스크롤을 만들지 않는다. 기록이나 선택지가 영역을 넘을 때 해당 패널만 스크롤한다. 작은 화면에서는 문서 스크롤을 허용하고 명령 도크를 장면 무대 아래로 이동한다.

---
## 저장 및 불러오기

상단바의 저장 버튼은 저장 모드로, 불러오기 버튼은 불러오기 모드로 같은 모달을 연다.

- 수동 슬롯 식별자를 `manual-1`부터 `manual-6`까지 확장한다.
- 자동 저장 슬롯은 기존과 같이 별도로 유지한다.
- 모달은 넓은 화면에서 2행×3열, 좁은 화면에서 한 열 또는 두 열로 재배치한다.
- 슬롯에는 번호, 장면 제목, 최근 기록 요약, 플레이 시간, 저장 시각을 표시한다.
- 저장 모드에서 빈 슬롯은 저장, 사용 중인 슬롯은 확인 후 덮어쓰기를 수행한다.
- 불러오기 모드에서 사용 중인 슬롯은 확인 후 복원하고 빈 슬롯은 비활성화한다.
- 삭제는 저장된 슬롯에만 제공하고 확인 후 수행한다.
- 기존 `manual-1`부터 `manual-3`까지의 데이터는 변환 없이 유지한다.
- 손상된 슬롯은 앱 전체를 중단하지 않고 해당 슬롯만 오류 상태로 표시한다.

---
## 설정과 영속성

플레이 화면의 설정 버튼은 게임 전용 설정 모달을 연다. 다음 설정을 로컬 저장소에 유지한다.

- `themeId`: `dark-fantasy`, `sci-fi`, `classic-novel`
- `resolutionId`: `fit`, `1280x720`, `1600x900`, `1920x1080`
- `aiProviderId`: `mock`

환경 설정은 버전이 있는 별도 데이터 구조로 저장한다. 값이 없거나 손상되면 기본값인 다크 판타지 글래스, 화면 맞춤, Mock AI로 복구한다.

---
## EXE 창 크기

- `fit`은 현재 모니터 작업 영역 안에서 창을 최대화한다.
- 고정 해상도는 요청 크기와 `window.screen.availWidth`, `window.screen.availHeight` 중 작은 값을 사용한다.
- 고정 해상도 적용 후 창을 화면 중앙으로 이동한다.
- 데스크톱 플랫폼에서만 Tauri 창 API를 호출한다.
- 웹 플랫폼에서는 창을 강제로 바꾸지 않고 같은 설정값으로 반응형 배치만 적용한다.
- 최소 창 크기 960×640은 유지한다.

Tauri 권한은 창 크기 변경과 중앙 이동에 필요한 항목만 추가한다. 외부 네트워크는 계속 차단한다.

---
## AI 공급자 선택

- Mock AI는 선택된 상태로 정상 동작한다.
- 로컬 GPU 모델 항목은 목록에 표시하지만 `연결 준비 중` 안내와 함께 비활성화한다.
- 실제 Ollama, LM Studio, OpenAI 호환 서버 탐색과 통신은 구현하지 않는다.
- 추천 답안은 현재 스토리 패키지의 사용 가능한 선택지를 Mock AI 추천 결과로 표현한다.

---
## 벡터 테마

세 테마는 같은 DOM 구조를 공유하고 CSS 변수와 SVG 장식만 변경한다.

- 다크 판타지 글래스: 보라색 유리 패널, 금속성 모서리, 룬 형태 아이콘
- 미니멀 SF HUD: 청록색 선, 각진 프레임, 상태 신호 아이콘
- 클래식 비주얼 노벨: 따뜻한 크림·장미색, 부드러운 프레임, 리본형 장식

SVG는 장식 모서리, 상태 아이콘, 저장, 불러오기, 설정, AI 아이콘에 사용한다. 장식은 의미 전달에 의존하지 않으며 스크린 리더에서 숨긴다.

---
## 접근성과 상호작용

- 모든 모달은 제목과 설명을 가진 대화상자로 제공한다.
- 모달이 열리면 첫 동작 요소로 초점을 이동한다.
- `Esc` 입력, 닫기 버튼, 배경 클릭으로 모달을 닫는다.
- 모달이 열린 동안 배경 조작을 막는다.
- 버튼과 상태는 색상 외에 문구와 아이콘으로 구분한다.
- `prefers-reduced-motion`에서는 장식 애니메이션을 제거한다.

---
## 호환성과 보안

- 기존 자동 저장 및 수동 저장 1~3번을 유지한다.
- 저장 스키마의 게임 상태 구조는 변경하지 않고 슬롯 식별자 범위만 확장한다.
- 외부 AI 연결, API 키 입력, 설치 프로그램 탐색 권한은 추가하지 않는다.
- 배포 CSP의 `connect-src 'none'` 설정을 유지한다.
- 브라우저 저장소 실패 시 메모리 저장소 대체 동작을 유지한다.

---
## 완료 조건

- 1280×720 이상의 데스크톱 화면에서 오른쪽 고정 패널과 문서 전체 세로 스크롤이 보이지 않는다.
- 중앙 장면 이미지와 반투명 스토리 상자가 동시에 보인다.
- 추천 답안과 직접 입력이 오른쪽 명령 도크에 표시된다.
- 상단바에서 홈 이동, 상태 확인, 저장, 불러오기, AI 선택, 설정을 사용할 수 있다.
- 수동 저장 슬롯 6개가 2행×3열로 표시되고 저장·불러오기·삭제가 동작한다.
- 세 테마와 네 해상도 설정이 재실행 뒤에도 유지된다.
- EXE에서 창 크기 변경이 적용되고 웹에서는 안전하게 무시된다.
- 기존 저장 데이터와 테스트가 유지된다.

---
## 제외 범위

- 실제 로컬 GPU 모델 연결
- 외부 AI 공급자 API 키 관리
- 새로운 장면 일러스트 생성
- 클라우드 저장 동기화
