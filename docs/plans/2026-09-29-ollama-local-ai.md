# 올라마 로컬 인공지능 연결 계획

---
## 목표

Windows 실행 프로그램에서 설치된 올라마 모델을 조회하고 선택하여 Text-Play 응답 생성에 사용한다.

---
## 전역 제약

- `main` 브랜치만 유지한다.
- 통신 대상은 `127.0.0.1:11434`로 고정한다.
- 올라마와 모델을 자동 설치하지 않는다.
- 웹 버전은 기존 임시 인공지능 동작을 유지한다.
- 설정 형식 버전 1을 버전 2로 안전하게 이전한다.
- 코드 각 줄에는 짧은 한글 주석을 작성한다.

---
## 작업 1: 설정 형식과 선택 계약

- 실패 테스트로 버전 1 이전과 올라마 모델 저장을 정의한다.
- 설정 형식을 버전 2로 변경한다.
- 임시 인공지능과 올라마 선택 생성기를 구현한다.
- 검증 명령: `pnpm exec vitest run tests/unit/text-play-preferences.test.ts tests/unit/desktop-llm.test.ts`

---
## 작업 2: 로컬 통신 어댑터

- 실패 테스트로 모델 목록, 스트리밍, 중단, 오류 변환을 정의한다.
- Tauri 호출 계층과 올라마 어댑터를 구현한다.
- Rust에서 고정 로컬 주소만 사용하는 명령을 구현한다.
- 검증 명령: `pnpm exec vitest run tests/unit/tauri-ollama-adapter.test.ts`

---
## 작업 3: 설정 화면과 실행 중 전환

- 실패 테스트로 모델 검색과 선택 저장을 정의한다.
- 데스크톱 플랫폼에 모델 조회 기능을 연결한다.
- 실행 중 공급자 변경이 다음 응답부터 반영되게 한다.
- 검증 명령: `pnpm exec vitest run tests/components/text-play-settings-dialog.test.tsx tests/integration/desktop-app.test.tsx`

---
## 작업 4: 전체 검증과 실행 파일

- 단위·컴포넌트·통합 테스트 전체를 실행한다.
- 정적 검사와 웹·데스크톱·Rust 빌드를 실행한다.
- Windows 설치 파일을 생성하고 해시를 기록한다.
- 검증 명령: `pnpm test:run`

---
## 검토 중점

- 임의 외부 주소 연결 가능성
- 선택 모델 삭제와 올라마 미실행 상태
- 응답 생성 중 중단 처리
- 설정 이전 후 데이터 손실 여부
- 기존 임시 인공지능 흐름 회귀 여부
