# MATE Text-Play Preview 0.1.0-preview.1

Windows에서 설치해 Mock 기반 텍스트 게임 흐름을 확인하는 미서명 시험판입니다. 실제 AI 서버와 계정·결제 기능은 연결되지 않았습니다.

---
## 지원 환경

- Windows 10·11 x64
- Microsoft Edge WebView2 Runtime
- 설치 과정에서 WebView2가 없으면 인터넷 연결을 통해 설치 프로그램 다운로드

---
## 설치 순서

1. EXE와 같은 이름의 `.sha256` 파일을 함께 다운로드합니다.
2. 아래 명령으로 SHA-256 값을 확인합니다.
3. EXE를 실행하고 설치 안내를 따릅니다.
4. 시작 메뉴에서 `MATE Text-Play Preview`를 실행합니다.

```powershell
Get-FileHash .\MATE-Text-Play-Preview_0.1.0-preview.1_x64-setup.exe -Algorithm SHA256
```

출력값이 `.sha256` 파일의 첫 번째 값과 같아야 합니다.

---
## 시험판 범위

- 샘플 새 게임과 이어하기
- 선택지와 제한형 자유 입력
- Mock AI 고정 응답
- 자동 저장 1개와 수동 저장 3개
- 로컬 IndexedDB 저장
- 외부 API 요청 차단

---
## 주의 사항

- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- 저장 데이터는 이 PC의 현재 Windows 사용자에게만 보관됩니다.
- 앱 제거·브라우저 데이터 정리·Windows 사용자 변경 시 저장 데이터가 유지되지 않을 수 있습니다.
- 실제 AI 서버, 로그인, 크레딧, 클라우드 저장, 자동 업데이트는 포함되지 않습니다.
- WebView2가 없는 PC에서 완전한 오프라인 설치는 지원하지 않습니다.

---
## 알려진 문제

- 설치 파일은 시험용 미서명 NSIS 패키지입니다.
- 실제 서비스 데이터와 동기화되지 않습니다.
- MSI 패키지와 자동 업데이트는 아직 제공하지 않습니다.
