# 공통 LLM 서비스 연결 설계

작성일: 2026-09-26

상태: 2단계 구현 기준, 외부 서버 계약 확인 후 변경 가능

---
## 1. 목적

기존 Character Chat과 Text-Play가 같은 LLM 연결 경계를 사용하도록 만든다. 브라우저에는 비밀키를 저장하지 않으며, 실제 모델명과 외부 서버 주소는 서버 환경 설정에서만 결정한다.

현재 확인된 ChatBot 소스에는 실제 LLM 서버 호출 코드와 모델명이 없고 `MockLLMAdapter`만 있다. 따라서 이번 단계에서는 특정 공급자나 모델을 추측하지 않고, 실제 서버를 안전하게 연결할 수 있는 공통 내부 계약을 구현한다.

---
## 2. 범위

- Character Chat과 Text-Play가 공유하는 HTTP LLM 어댑터
- 동일 출처 `/api/llm` 서버 프록시
- 서버 전용 외부 엔드포인트와 토큰 환경 변수
- 일반 채팅, 구조화 게임 응답, 대화 요약 모드
- 스트리밍 중단 전달
- 인증 필요, 크레딧 부족, 사용량 제한, 서비스 장애와 잘못된 응답 구분
- 실패한 Text-Play 자유 입력의 수동 재시도
- Mock과 서버 모드 상태 표시

범위에서 제외하는 항목은 실제 사용자 로그인, 결제, 서버 크레딧 차감, 특정 모델명 지정이다. 이 항목은 외부 서버 계약이 확인된 뒤 연결한다.

---
## 3. 내부 요청 계약

브라우저는 같은 출처의 `/api/llm`에 다음 세 모드 중 하나를 전송한다.

- `chat`: 기존 캐릭터, 대화방과 최근 메시지
- `structured`: Text-Play 시스템 규칙, 최소 게임 문맥, 사용자 입력과 응답 스키마
- `summary`: 대화방과 요약 대상 메시지

스트리밍 응답은 줄 단위 JSON을 사용한다.

- `{"type":"chunk","content":"..."}`
- `{"type":"done"}`

요약 응답은 `{"summary":"..."}` JSON을 사용한다.

---
## 4. 서버 프록시

서버 프록시는 `MATEVERSE_LLM_API_URL`의 정확한 주소로 요청을 전달한다. 경로를 임의로 덧붙이지 않는다. `MATEVERSE_LLM_API_TOKEN`이 있으면 서버에서만 Bearer 인증 헤더를 추가한다.

브라우저의 쿠키, Authorization 헤더와 임의 헤더는 외부 서버로 전달하지 않는다. 요청 본문은 64KiB 이하의 검증된 세 모드만 허용한다. 외부 응답 본문은 스트림을 유지해 브라우저로 전달한다.

---
## 5. 공급자 선택

`NEXT_PUBLIC_LLM_MODE=server`이면 Character Chat과 Text-Play 모두 HTTP 어댑터를 사용한다. 그 외 값과 기본값은 Mock을 사용한다. 실제 연결 정보가 없는 개발 환경에서도 기존 기능은 계속 동작한다.

화면에는 `Mock AI` 또는 `서비스 AI` 상태를 표시한다. 이 표시는 모델명을 뜻하지 않고 현재 호출 경로만 나타낸다.

---
## 6. 오류와 재시도

- `401`: 로그인이 필요한 상태
- `402`: 서비스 크레딧 부족
- `429`: 요청 한도 초과
- `502`·`503`·`504`: LLM 서비스 연결 실패
- 잘못된 스트림·JSON: 응답 형식 오류
- 사용자 중단: 기존 확정 게임 상태 유지

자동 재시도는 중복 과금 가능성이 있어 사용하지 않는다. Text-Play는 실패한 입력을 유지하고 사용자가 누르는 `다시 시도` 버튼을 제공한다.

---
## 7. 보안 경계

- 비밀키와 외부 API 주소의 클라이언트 번들 포함 금지
- 외부 응답의 게임 액션 직접 적용 금지
- 기존 응답 스키마와 액션 검증 이후에만 게임 상태 변경
- 외부 서버로 브라우저 쿠키와 사용자 Authorization 전달 금지
- 서버 미설정 시 명시적인 503 응답

---
## 8. 검증 기준

- 두 화면이 같은 공급자 생성기를 사용한다.
- 스트리밍 조각이 순서대로 출력된다.
- 중단 신호가 실제 HTTP 요청에 전달된다.
- 상태 코드별 사용자 안내가 구분된다.
- 실패 입력을 다시 시도할 수 있다.
- 서버 미설정, 과대 본문과 잘못된 모드는 외부 호출 전에 거부된다.
- 실제 서버가 없어도 Mock 모드의 기존 테스트와 플레이가 유지된다.

---
## 9. 이미지 판단

이번 단계는 연결 상태와 오류 동작을 추가하는 작업으로 기존 UI의 텍스트 배지와 버튼만으로 의미 전달이 충분하다. 새 래스터 이미지나 벡터 이미지는 추가하지 않는다.
