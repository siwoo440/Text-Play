# 개발 로드맵

로드맵은 개발 순서를 설명하며 일정 확정 문서가 아닙니다. 사용자 검토와 구현 중 확인된 위험에 따라 순서를 조정합니다.

---
## 1단계 — 웹 MVP

- [x] Text-Play 공식 샘플 패키지
- [x] 결정형 게임 엔진
- [x] Story Mode와 제한형 Hybrid Mode
- [x] 자동 저장 1개와 수동 저장 6개
- [x] 반응형 홈·플레이 화면
- [x] 기존 Character Chat 데이터 격리
- [x] 브라우저 자동 저장·이어하기 검증

1단계 기능 구현과 검증은 완료했습니다. 화면 구성과 세부 사양은 이후 검토 결과에 따라 계속 변경할 수 있습니다.

---
## 2단계 — 서비스 연결

- [x] Character Chat과 Text-Play의 공통 LLM 어댑터
- [x] 같은 출처 서버 프록시와 서버 전용 비밀키 경계
- [x] 오류·취소·수동 재시도 처리
- [x] 대화와 게임 상태의 최소 컨텍스트 요청 형식
- [ ] 기존 챗봇 서비스의 실제 API 주소·모델·응답 계약 연결
- [ ] 계정·인증과 실제 크레딧 정책 연결

2단계의 2A 연결 기반은 완료했습니다. 기존 챗봇 소스에도 실제 서버 계약이 포함되어 있지 않아 실서비스 연결과 계정·크레딧 연동은 확인 가능한 계약을 받은 뒤 진행합니다.

## 5단계 — 운영 확장

- 작품 카탈로그와 다운로드 서버

---
## 현재 개발 단계별 우선순위

1. 기준 정리: ChatBot 확정 커밋 동기화, 도구 버전 고정, 문서·검증 기록 일치
2. 대표 작품: 장면 15~20개, 장면·엔딩 이미지, 추천 행동 보강
3. 내장 AI: 응답 품질, 모델 다운로드·설치 연결
4. 품질: 화면별 코드 분리, 성능 측정, 해상도·테마·EXE 기능 검증
5. 배포: 버전 관리, Release, 설치·업데이트·제거 검증과 코드 서명
6. 온라인 확장: 실제 계정·AI·크레딧·기록 동기화, `.mateplay` 규격

2026-10-26 1단계의 변경과 검증 결과는 [개발 기록](DEVELOPMENT-LOG.md)의 같은 날짜 항목을 기준으로 확인합니다. 역사적 단계의 완료 표시는 실제 서버 운영이나 모델 자동 배포 완료를 뜻하지 않습니다.
