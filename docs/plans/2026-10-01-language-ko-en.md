# 한국어·영어 버전 나누기 계획

---
## 목표

- 사용자가 언어(한국어 / English)를 고르면 **AI의 다음 답변이 그 언어로** 나온다.
- 화면 글자도 고른 언어로 바뀐다. 범위는 앱 전체(ChatBot 화면 포함)다.
- 언어는 Text-Play 설정 창에서 고른다(사용자 결정, 2026-10-01). 고른 언어는 앱 전체 설정으로 저장한다.

---
## 확정한 결정

- 언어 값은 `ko`·`en` 두 가지, 기본값 `ko`.
- 저장 위치: Text-Play 설정(`mate.text-play.preferences.v2`)에 `language` 필드를 더한다. 예전 저장값에는 없으므로 읽을 때 `ko`로 채운다(형식 버전은 그대로).
- 화면 글자는 화면 묶음마다 `ko`·`en` 사전 파일을 두는 방식으로 옮긴다(`defineText(한국어, 영어)`로 정의해 영어 키 누락은 타입 검사로 잡음).
- 작품 내용(제목·장면 서술·선택지·엔딩·용어집)은 작품별 영어판 덮어쓰기(`translations.en`)로 둔다. 영어판이 없는 작품은 한국어 원문을 쓰되 AI 답변은 고른 언어로 한다.
- `src/chatbot`은 직접 고치지 않는다. ChatBot 화면 번역은 ChatBot 저장소에 언어 기능이 들어간 뒤 동기화로 가져온다.

---
## 단계

| 단계 | 내용 | 확인 |
| --- | --- | --- |
| 1. 기반 | 언어 설정 저장·불러오기, Text-Play 설정 창의 `언어 / Language` 선택, 문서 `lang` 반영 | 설정 테스트, 화면 테스트 |
| 2. AI 답변 | 문맥·이야기꾼 규칙·예시를 고른 언어로 만들고, 발화자 이름·작품 내용 영어판 사용, 임시 인공지능도 영어 응답 | 문맥 테스트, exe에서 영어 답변 |
| 3. 화면 | Text-Play 플레이·홈·설정·저장 창 → 사이드바·상단 바·AI 모델 화면의 영어판 | 화면 테스트, exe 캡처 |
| 4. ChatBot 화면 | ChatBot 저장소에 언어 기능(같은 `ko`·`en`, 설정 연동 방법) 요청 → 동기화 | ChatBot 쪽 작업 후 |

## 진행 기록

- 1단계 완료: `AppLanguage`(`text-play-preferences.ts`), 설정 창 `언어 / Language`, 문서 `lang` 반영.
- 2단계 완료:
  - 작품 영어판 형식 `TextPlayPackageTranslation`(`core/types.ts`)과 샘플 작품 영어판(`demo-package.ts`).
  - `localize-package.ts`: 고른 언어의 작품을 만들고(식별자·규칙은 그대로, 글만 바꿈), 저장된 한국어 장면 서술·선택지 기록을 영어로 바꿔 AI 문맥에 넣는다.
  - `context-builder.ts`: 이야기꾼 규칙·예시·문맥 문구를 언어별로 두고 `language`를 AI 요청에 담는다. 발화자 목록도 고른 언어 이름(영어는 `Lyra`).
  - 응답 길이 상한: 한국어 서술 300·대사 150자, 영어 서술 600·대사 300자(같은 뜻에 글자가 더 많음).
  - 언어 전달: 설정 → `DesktopRoutes` → `TextPlayProvider` → 세션 제어기. 언어를 바꾸면 **다음 답변부터** 그 언어로 나온다(이미 나온 기록은 그대로).
  - 임시 인공지능도 영어를 고르면 영어 응답.

- 3단계 완료:
  - 기반: `src/features/text-play/i18n/localized-text.ts`(`defineText`, `dateLocale`), `useAppLanguage()`(`TextPlayPreferencesProvider.tsx`, 공급자 밖에서는 `ko`).
  - 사전 파일: Text-Play 화면 `ui/text-play-ui-text.ts`(플레이·이야기 기록·추천·상태·저장·설정·메인·대화상자), 세션 안내 `session/session-messages.ts`(오류·저장 안내), 데스크톱 틀 `src/desktop/desktop-ui-text.ts`(화면 제목·사이드바 메뉴·상단 바·Text-Play 대화방·AI 이름), AI 모델 화면 `ai-models/ai-model-view.ts`(`AI_MODELS_TEXT`).
  - 작품 내용: 장면 제목·선택지·상태 패널(인물·아이템·퀘스트 이름)·저장 창·사이드바 기록이 작품 영어판을 따른다. 저장된 한국어 장면 서술·선택 기록도 영어로 보여 준다(AI가 이미 한 말은 그대로).
  - 한국어 화면도 내부 식별자 대신 표시 이름을 쓴다: 장면 위 장소(`FOREST-GATE` → 장면 제목과 같으면 생략), 상태 패널의 아이템·퀘스트, 대사 화자(`lyra` → 리라), 저장 슬롯의 장면 식별자 줄 삭제.
  - 언어를 바꿔도 저장을 다시 불러오지 않도록 세션 안내는 참조로 읽는다(테스트 포함).
  - 남은 한국어: ChatBot 화면(사이드바 대화방 목록·캐릭터·설정 화면 등, 4단계), 사용자가 정한 이름, 메인의 샘플 작품 외 작품 50개 내용(제목·소개·태그, 장르 이름은 영어), 엔진(Rust)이 보내는 실패 이유 문구.

## ChatBot 쪽 요청(4단계)

ChatBot 저장소 세션에 그대로 전달할 요청입니다.

> Text-Play exe가 한국어·영어를 나눴습니다(exe 설정 창에서 고르고, 값은 `ko`·`en`, 기본 `ko`). exe는 ChatBot 화면을 `src/chatbot`으로 그대로 가져다 쓰므로, ChatBot 쪽에 다음을 넣어 주세요.
> 1. 앱 언어 값 `ko`·`en`(기본 `ko`)과 화면 글자 사전. 사이드바 대화방 목록(정렬·검색·새 캐릭터 만들기·보관함), 대화·스토리 화면, 캐릭터 상세·만들기, 탐색·내 작품, 설정·고객 지원, 사용자 패널, 19+ 스위치부터.
> 2. 밖에서 언어를 정하는 방법: `AppProvider`에 `language` 속성을 받거나, 같은 브라우저 저장 키를 읽는 방식 중 하나. exe는 `AppProvider language={설정 언어}`로 넘길 예정입니다.
> 3. 캐릭터 대화 AI 응답 언어도 같은 값을 따르기(시스템 규칙에 "영어로만 답한다" 같은 줄 추가).
> 4. 문서 `lang`과 날짜·숫자 표시(`ko-KR`·`en-US`)도 같은 값으로.
> 5. 캐릭터·작품 데이터 번역은 이번 범위 밖(이름·소개는 원문 유지)으로 두어도 됩니다.

ChatBot에 반영되면 `pnpm chatbot:sync`로 가져오고, `DesktopApp.tsx`에서 Text-Play 설정의 언어를 ChatBot 쪽으로 넘긴다.
