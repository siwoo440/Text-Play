# 한국어·영어 버전 나누기 계획

---
## 목표

- 사용자가 언어(한국어 / English)를 고르면 **AI의 다음 답변이 그 언어로** 나온다.
- 화면 글자도 고른 언어로 바뀐다. 범위는 앱 전체(ChatBot 화면 포함)다.
- 언어는 Text-Play 설정 창에서 고른다(사용자 결정, 2026-10-01). 고른 언어는 앱 전체 설정으로 저장한다.

---
## 확정한 결정

- 언어 값은 `ko`·`en` 두 가지, 기본값 `ko`.
- 저장 위치: Text-Play 설정(`mate.text-play.preferences.v2`)에 `language` 필드를 더한다. 예전 저장값에는 없으므로 읽을 때 `ko`로 채운다(형식 버전은 그대로).
- 화면 글자는 컴포넌트 옆에 `ko`·`en` 사전을 두는 방식으로 옮긴다(키 누락은 타입 검사로 잡음).
- 작품 내용(제목·장면 서술·선택지·엔딩·용어집)은 작품별 영어판 덮어쓰기(`translations.en`)로 둔다. 영어판이 없는 작품은 한국어 원문을 쓰되 AI 답변은 고른 언어로 한다.
- `src/chatbot`은 직접 고치지 않는다. ChatBot 화면 번역은 ChatBot 저장소에 언어 기능이 들어간 뒤 동기화로 가져온다.

---
## 단계

| 단계 | 내용 | 확인 |
| --- | --- | --- |
| 1. 기반 | 언어 설정 저장·불러오기, Text-Play 설정 창의 `언어 / Language` 선택, 문서 `lang` 반영 | 설정 테스트, 화면 테스트 |
| 2. AI 답변 | 문맥·이야기꾼 규칙·예시를 고른 언어로 만들고, 발화자 이름·작품 내용 영어판 사용, 임시 인공지능도 영어 응답 | 문맥 테스트, exe에서 영어 답변 |
| 3. 화면 | Text-Play 플레이·홈·설정·저장 창 → 사이드바·상단 바·AI 모델 화면의 영어판 | 화면 테스트, exe 캡처 |
| 4. ChatBot 화면 | ChatBot 저장소에 언어 기능(같은 `ko`·`en`, 설정 연동 방법) 요청 → 동기화 | ChatBot 쪽 작업 후 |

---
## 진행 기록

- 1단계 완료: `AppLanguage`(`text-play-preferences.ts`), 설정 창 `언어 / Language`, 문서 `lang` 반영.
- 2단계 완료:
  - 작품 영어판 형식 `TextPlayPackageTranslation`(`core/types.ts`)과 샘플 작품 영어판(`demo-package.ts`).
  - `localize-package.ts`: 고른 언어의 작품을 만들고(식별자·규칙은 그대로, 글만 바꿈), 저장된 한국어 장면 서술·선택지 기록을 영어로 바꿔 AI 문맥에 넣는다.
  - `context-builder.ts`: 이야기꾼 규칙·예시·문맥 문구를 언어별로 두고 `language`를 AI 요청에 담는다. 발화자 목록도 고른 언어 이름(영어는 `Lyra`).
  - 응답 길이 상한: 한국어 서술 300·대사 150자, 영어 서술 600·대사 300자(같은 뜻에 글자가 더 많음).
  - 언어 전달: 설정 → `DesktopRoutes` → `TextPlayProvider` → 세션 제어기. 언어를 바꾸면 **다음 답변부터** 그 언어로 나온다(이미 나온 기록은 그대로).
  - 임시 인공지능도 영어를 고르면 영어 응답.

---
## ChatBot 쪽 요청(4단계)

- ChatBot 앱에 언어 값(`ko`·`en`)과 화면 글자 사전을 넣는다.
- exe가 언어를 알려 줄 수 있게 언어를 밖에서 정하는 방법(예: `AppProvider`의 언어 속성 또는 같은 저장 키)을 둔다.
- ChatBot AI 응답 언어도 같은 값을 따른다.
